## @{keyword.statement}

@{lang.en}
You are given $K$ permutations $P_0, P_1, \ldots, P_{K-1}$ of $\{0,1,\ldots,N-1\}$.
Find the order of the group generated by these permutations, modulo $@{param.MOD}$.

More precisely, find the number of distinct permutations obtainable by composing the given permutations and their inverses any number of times, including zero times (the identity permutation).
The composition of permutations $p$ and $q$ is the permutation $r$ defined by $r_i=p_{q_i}$.
@{lang.end}

## @{keyword.constraints}

- $1 \leq N \leq @{param.N_MAX}$
- $1 \leq K \leq @{param.K_MAX}$
- Each $P_i$ is a permutation of $\{0,1,\ldots,N-1\}$.

## @{keyword.input}

```
$N$ $K$
$P_{0,0}$ $P_{0,1}$ ... $P_{0,N-1}$
$P_{1,0}$ $P_{1,1}$ ... $P_{1,N-1}$
$\vdots$
$P_{K-1,0}$ $P_{K-1,1}$ ... $P_{K-1,N-1}$
```

## @{keyword.output}

Output the answer.
