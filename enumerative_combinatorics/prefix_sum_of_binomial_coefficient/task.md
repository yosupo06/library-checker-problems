## @{keyword.statement}

@{lang.en}
This problem has $T$ cases.

Given integers $N, K$, print $\displaystyle\sum_{i=0}^K \binom{N}{i}$ modulo $@{param.MOD}$.
@{lang.ja}
この問題は $T$ ケースあります。

整数 $N, K$ が与えられます。$\displaystyle\sum_{i=0}^K \binom{N}{i}$ を $@{param.MOD}$ で割ったあまりを出力してください。
@{lang.end}

## @{keyword.constraints}

- $1 \leq T \leq @{param.T_MAX}$
- $0 \leq K \leq N \leq @{param.N_MAX}$

## @{keyword.input}

```
$T$
$N_1$ $K_1$
$\vdots$
$N_T$ $K_T$
```

## @{keyword.output}

@{lang.en}
For each case, print the answer on a separate line.
@{lang.ja}
各ケースについて、答えを $1$ 行に出力してください。
@{lang.end}
